# McCumber Cube Interactive

Interactive 3D visualization of the McCumber Cube information security framework.

## Overview

The McCumber Cube, introduced by John McCumber in 1991, is a three-dimensional model for comprehensive information security analysis. It maps 27 cells (3 x 3 x 3) across three dimensions:

1. **Security Goals (CIA Triad)**: Confidentiality, Integrity, Availability
2. **Data States**: At Rest, In Transit, In Processing
3. **Countermeasures**: Technology, Policies & Practices, Education & Training

## Features

- Rotating 3D cube with clickable cells
- Dimension selector with bidirectional highlighting across the cube and the reference table
- Detail panel showing the security requirement for each of the 27 cell combinations
- Full 27-cell reference matrix with concrete examples
- Multilingual support: English, Romanian, Russian
- Single self-contained HTML files with no external dependencies

## Interactive Visualizations

- **McCumber Cube**: [mccumber-cube-interactive-index.html](mccumber-cube-interactive-index.html) - 3D rotating cube with 27 clickable cells
- **OSI Reference Model**: [osi-model-interactive.html](osi-model-interactive.html) - Interactive 7-layer OSI model with EN/RO/RU language switching and mnemonic phrases

## Usage

Open any HTML file in a modern browser.
